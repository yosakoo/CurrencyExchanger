# Правила для слоя репозитория и БД

## SQL и sqlc
- Новые запросы писать в `internal/repository/queries/*.sql`
- После добавления SQL запустить `make generate` для обновления Go-кода
- Не писать SQL вручную в Go-коде — только через сгенерированный sqlc

## Миграции
- Создавать только через `migrate create -ext sql -dir migrations -seq <name>`
- Каждая миграция должна иметь `up` и `down` версию
- Миграции необратимы после мержа в main — не редактировать существующие

## Транзакции
- Транзакции пробрасывать через context — смотри `internal/repository/tx.go`
- Не создавать транзакции внутри репозитория — это ответственность service-слоя

## Денежные значения
- Хранить и передавать в копейках (int64)
- Никаких float для денег
- Конвертация в рубли только на уровне хендлера для ответа клиенту
