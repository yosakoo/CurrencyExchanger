# Команда /standup
# Генерирует стендап-сообщение по git-истории за последние 24 часа.
# Использование: /standup

Выполни следующие команды и проанализируй результат:

1. `git log --since="24 hours ago" --oneline --author="$(git config user.name)"` — список коммитов
2. `git diff --since="24 hours ago" --stat HEAD~$(git log --since="24 hours ago" --oneline --author="$(git config user.name)" | wc -l) HEAD` — статистика изменений (если есть коммиты)
3. `git log --since="24 hours ago" --author="$(git config user.name)" -p --no-merges` — полный диф изменений

На основе дифа пойми **что именно было сделано**: какие функции добавлены, какие баги исправлены, какие файлы затронуты и почему. Не пересказывай названия коммитов — объясни суть изменений.

Сформируй стендап в формате:

**Что сделано вчера:**

- (опиши суть изменений на основе дифа, человекочитаемо, без хешей и имён файлов если не важно)

**Что планируется сегодня:**

- (спроси меня или оставь пустым)

**Блокеры:**

- Нет (или укажи если я скажу)

Пиши кратко, по-деловому. Технические детали только если они важны для команды.
