# Команда /standup
# Генерирует стендап-сообщение по git-истории за последние 24 часа.
# Использование: /standup

Посмотри `git log --since="24 hours ago" --oneline --author="$(git config user.name)"` и сформируй стендап в формате:

**Что сделано вчера:**
- (перечисли коммиты человекочитаемо, без хешей)

**Что планируется сегодня:**
- (спроси меня или оставь пустым)

**Блокеры:**
- Нет (или укажи если я скажу)

Пиши кратко, по-деловому. Технические детали только если они важны для команды.
