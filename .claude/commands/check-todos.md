# Команда /check-todos
# Находит все TODO/FIXME/HACK комментарии в проекте и группирует по приоритету.
# Использование: /check-todos

Найди все комментарии TODO, FIXME, HACK, XXX в проекте (исключи vendor/, node_modules/, .git/).

Сгруппируй по категориям:

**FIXME / критичное:**
- файл:строка — описание

**TODO / задачи:**
- файл:строка — описание

**HACK / технический долг:**
- файл:строка — описание

Итого: N комментариев. Предложи с чего начать.
