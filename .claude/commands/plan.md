# Команда /plan
# Составляет детальный план реализации фичи или задачи.
# Использование: /plan <описание задачи>

Прочитай CLAUDE.md и ключевые файлы проекта чтобы понять архитектуру. Затем составь план реализации для задачи, которую описал пользователь.

## Формат плана

**Задача:** (одно предложение — что делаем и зачем)

**Затронутые компоненты:**

- (перечисли файлы/пакеты которые нужно создать или изменить)

**Шаги реализации:**

1. (конкретный шаг с указанием файла и что именно делаем)
2. ...

**Возможные сложности:**

- (edge cases, неочевидные зависимости, риски)

**Вопросы перед стартом:**

- (что нужно уточнить у пользователя прежде чем начинать)

## Правила

- Предлагай минимально достаточное решение — не усложняй без необходимости
- Указывай конкретные файлы и функции, а не абстрактные слои
- Если задача неоднозначна — сначала уточни, потом планируй
- После составления плана спроси: "Начинаем реализацию?"
